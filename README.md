# Pulse Fit - site fictício de personal trainers

Site de demonstração (página única, HTML/CSS/JS puros, sem build).

- Todos os dados de contato, personais, CREFs e preços são **fictícios**.
- Fotos de exercícios: Pexels (licença sem crédito obrigatório).
- Imagem em `fotos/ilustracao/`: gerada por IA, apenas ilustrativa.

Para publicar: abra `index.html` ou envie a pasta para qualquer hospedagem estática (ex.: GitHub Pages).
